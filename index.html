Has this been audited?

No — and we're not going to blur that line. Here's exactly what has and hasn't happened.

The token and vesting contracts are source-verified on the block explorer — that confirms the deployed bytecode matches the published Solidity exactly. It's a transparency check: it proves the code shown is the code running, so you can read it yourself instead of trusting a description of it.

What it is not: a professional third-party security audit. We ran the contracts through Auditrace, an automated static-analysis tool — it flags known patterns, but it can't compile, execute, or guarantee full coverage. No Critical or High findings came back; the remaining Medium ones are noted and explained in the code comments themselves.

The NOCAP LP lock was also covered by an AI-assisted security review of the BlockDAG contracts we've built (Reef, Nodal, Handshake, COOKED and this lock). Its functions and settings match the published source, and on 2 October it held 99.99% of the NOCAP/BDAG pool's LP tokens, locked until 25 March 2027. That review is AI-assisted, not an independent audit, and it didn't cover the NOCAP token contract itself.

$NOCAP is experimental software on an early-stage chain (BlockDAG, chain 1404). Treat any amount you put in as money you could lose entirely — only ever risk what you're fully comfortable losing.
